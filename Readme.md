Project Overview：
Prism Journey is a 3D path-decision + environmental interaction game built in Unity where the player changes color identity to interact with the environment. The player can pass or be blocked by objects depending on color compatibility. The game also includes interactions such as traps, moving obstacles, and environmental challenges that require timing and strategic movement. Players must navigate paths, avoid hazards, and solve color-based puzzles while progressing through levels. The system also features enemy AI behavior and boss encounters that challenge the player's understanding of game mechanics. The goal of this project is to design a modular game architecture with scalable gameplay systems, including color interaction, based challenges, and combat mechanics
